# News in Levels · 专注阅读

Chrome Manifest V3 扩展，统一美化 News in Levels 首页、等级／分类文章列表、列表分页和文章详情页。

同样支持 Days in Levels（`daysinlevels.com`）首页、等级／历史分类列表及 `/article/` 文章页。顶部提供 News／Days 互相跳转，两个网站共用阅读偏好。Days 的原生音频在正文上方显示，加载失败或临时链接过期时提供刷新重试入口。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目的 `extension` 文件夹（其中包含 manifest.json）。
4. 刷新已打开的 News in Levels 文章页面。

也可以先解压 `news-in-levels-reader.zip`，然后选择解压后的文件夹加载。无需构建或安装依赖。

## 功能

- 自动去除文章以外的导航、侧栏、广告、推广、评论等界面干扰。
- 保留标题、日期、文章图片、正文、难词、等级链接、音视频和文末思考题。
- SoundCloud 音频在正文上方显示为简洁播放条，提供播放／暂停、进度拖动和时长；保留平台来源链接。连接中禁用播放，收到播放器就绪通知后启用；点击播放后单独显示缓冲状态。18 秒未就绪或 12 秒未开始播放时提供重试入口，仍可接收迟到的就绪／播放通知。
- 随时可展开 SoundCloud 原播放器，便于处理平台提示；重试会重新加载播放器，进度归零。不自动播放，不下载或绕过平台音频地址。
- SoundCloud 播放条提供 0.75×、1×、1.25×、1.5×、2× 速度选择并保存偏好。扩展在 `https://w.soundcloud.com/player/*` 的播放器框架内控制媒体速度并保留音调，兼容延迟创建的音频。此功能依赖播放器内部使用浏览器媒体元素，SoundCloud 调整内部实现后可能需要更新。更新后请重新加载扩展和文章页，以启用新增的 SoundCloud 站点访问。
- 提供浅色／深色主题、16–30px 字号调节；偏好本地保存。
- 正文使用普通 DOM 和限定范围的样式，便于划词翻译插件读取选区。仅隐藏标记的原站容器，保留后续插入的翻译弹窗；具体兼容性仍取决于第三方插件的实现。
- 「查看原网页」可以临时恢复原站，「返回专注阅读」恢复阅读界面。
- 顶部保留首页、三个等级的文章列表导航，底部提供同等级上一篇（较新）／下一篇（较早）。相邻文章从原站列表读取，支持列表分页；最多查找 10 页，网络异常或未找到时提供文章列表入口。
- 在页面加载开始时隐藏原站界面，正文和阅读偏好就绪后显示，避免切换等级时先出现原站。无法识别文章或初始化超时会自动显示原页。
- 首页、等级列表、分类列表提供文章图片、日期、摘要和 Level 1／2／3 入口；保留原站分页和分类筛选。列表和文章共用主题、字号和恢复原网页功能。
- 适配手机宽度和打印。联系等其他页面保留原站界面。

扩展只申请 `storage` 权限，没有后台服务、统计或远程脚本。为了查找相邻文章，会读取同站、同等级的文章列表。文章图片与播放器仍使用网站原有第三方资源。隐藏广告是界面清理，并不拦截原网页的网络请求。网页结构无法识别时保留原网页。

## 验证

`tests/reader.cjs` 使用下载的真实网页 `source-sample.html` 离线验证提取、等级、媒体、设置、原页恢复、移动端溢出及非文章页回退。需 Node.js、Playwright 和 Microsoft Edge。设置 `PLAYWRIGHT_PATH` 可指定 Playwright 包的绝对路径，然后运行 `node tests/reader.cjs`。

离线测试不验证第三方播放器的在线播放；安装后可在文章页点击播放检查。若网站未来修改正文结构，需更新 `reader.js` 的选择器。

`node tests/listing.cjs` 使用真实首页和等级列表 HTML 检查卡片提取、等级入口、分页链接、分类参数、主题、移动布局及原页切换。分类和分页路由使用等级列表 HTML 作为结构回归样本。

## 更新扩展

在 `chrome://extensions/` 找到本扩展，点击重新加载按钮，再刷新已打开的文章页。使用压缩包安装的用户需先用新版本文件替换原安装目录中的文件。
